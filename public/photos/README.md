# Photographs

Generated images for a made-up eight-screen theatre and four made-up films, made in Canva. They are not photographs of a real place or real
work. A real business replaces every file here with its own.

**The files in this folder are low-resolution stand-ins** (enlarged from 200px previews), so the
pages can be laid out and reviewed. The full-size originals are in Canva; download each and save
it over the file of the same name, then restart.
